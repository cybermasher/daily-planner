# Daily Drill Planner

A lightweight, responsive, installable planner inspired by a lacrosse practice plan.

## Features
- Timed daily blocks / drills
- Drag a drill between phases
- Double-click any drill to edit
- Add/delete/rearrange by editing the JSON if desired
- Local browser autosave
- Export/import a day as JSON
- Responsive phone/tablet/desktop layout
- PWA-ready for installation as an app when hosted on HTTPS

## Cross-device use
This version intentionally has no account/backend, so browser data is local to each device.
For true cross-device sync, host the app and add a small cloud database/auth layer (e.g. Supabase/Firebase). The UI/data model is already structured for that next step.

Late afternoon/evening = hobbies, people, recreation.
